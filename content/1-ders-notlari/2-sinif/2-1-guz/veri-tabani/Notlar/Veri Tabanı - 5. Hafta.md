title: Veri Tabanı Yönetim Sistemleri - 5. Ders

### INSERT

```sql
INSERT INTO <table> 
(<kolon1>,<kolon2>)
VALUES
(<value1>, <value2>)
```


### DELETE

 - Ders kapsamındaki uygumalar ekseriyetle sınava yönelik olacak

```sql
DELETE FROM <table>
WHERE
<kolon1> = <value>
```


### UPDATE

```sql
UPDATE table_name
SET column1= value1, column2 = value2 ...
WHERE condition;
```
